# Changelog

## 0.1.0

- Four tools: `session_open`, `session_send`, `session_wait`, `session_status`.
- Sibling sessions only: created through `sessionController.create`, never with a parent link.
- Approval policy inherited from the opening session; model defaults to the opener's and is recorded per session.
- Dispatch restricted to the same project; at most 8 open peers per workspace, counted by the
  `session-spawn-` session-id prefix so a restart keeps the count and archiving frees a slot.
- Titles are generated by DSH; the plugin only reads them.
